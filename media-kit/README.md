# Never Roam Alone — Media Kit

Open `index.html` for the full kit (facts, boilerplate, logo, colors, type, screenshots, social graphics, captions).
`copy.md` has all the text in plain form. PDF versions: `never-roam-alone-media-kit.pdf` (the full kit, A4),
`never-roam-alone-fact-sheet.pdf` (one page) and `never-roam-alone-media-kit-copy.pdf` (text only).
`print/` holds the HTML sources for the fact sheet and copy PDFs. `assets/` holds every file:

- `assets/logo/` — transparent PNG mark (1024/512/256), on-sand and on-white versions, square profile pictures (sand and card grounds)
- `assets/screenshots/` — desktop (2880×1800) and mobile (1170×2532) captures, September 2026
- `assets/social/` — Instagram/Facebook square, city spotlight, story, X header, Facebook cover (lower band kept clear for the profile picture), link card, default share image

Rebuild note: the screenshots and social graphics were rendered from the live site with headless Chrome;
regenerate them when the design or the city count changes (the count appears in the graphics and copy).

Once deployed with the site, this folder is reachable at https://neverroamalone.com/media-kit/
