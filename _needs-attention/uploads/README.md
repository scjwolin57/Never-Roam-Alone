# Your own landmark photos

Drop image files here (jpg / jpeg / png / webp), then pick them from the
"Use my own photo" panel on the review page — the dropdown lists whatever
is in this folder.

Naming is free-form; the review page shows a preview so you can confirm you
picked the right one. Landscape shots work best (the guide's card grid and
map column suit roughly 3:2), but portrait is fine too now that the modal
adapts to the photo's orientation.

Files here are working input only. Applying a photo copies it to
images/landmarks/<city>-<landmark>.webp — this folder is never published.
