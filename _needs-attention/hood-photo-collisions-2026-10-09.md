## What was checked

Every entry in hood-photos.js (3,136 entries in 886 cities). For the 3,054 Commons files that still exist:

| Evidence used | Files |
|---|---|
| The file's own GPS (Commons coordinates) | 2,198 |
| Commons structured data: place of creation, depicts, camera position | 150 |
| Commons categories linked to a Wikidata place with coordinates | 451 |
| No coordinates anywhere: title and categories read by hand where they did not name the city or country | 255 |

Each point was measured against the hood's own point in citydata (hood_geo), or the city point if the hood has none. Over 30 km = flagged, then each flag was read by hand. Coarse evidence (a whole country, region or province centre point) was cleared by hand: 11 such false alarms are not listed (for example Cape Town, Gilgit, Banda Aceh).

Flickr: 39 photos, GPS read from the Flickr page. Pexels: 24, location field read in the browser (it is often the photographer's home town, so only the title and caption count). Pixabay: 14, no location data; titles name the place except 3 generic ones (see the end). Wikipedia: 2, fine.
